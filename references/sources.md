# 文献の探し方

## CiiiiNiiiiiiii（シーニィ）

章立てと文章の展開には[比較から得た執筆指針](writing-patterns.md)を使う。特定の論文の成果・数値・図表を引用するときや、利用者が新しい収録例を求めたときに、該当資料を開く。

利用者の手元に取得済みの `ciinii-sources.zip` があれば、ZIP内の `catalog.json` を題名・資料種別で検索する。`file` がZIP内の相対パス、`article` が詳細ページである。対象の本文、必要なら同じ番号の発表資料だけを読む。公開のスキル単体でも執筆指針は使える。

該当資料が手元にない場合は[データベース](https://ciiiiniiiiiiii.lanet.sist.chukyo-u.ac.jp/)の「論文」タブで研究対象や手法を検索し、詳細ページから本文を確認する。卒論と学会発表の資料種別を確認する。

認証済みのブラウザで閲覧できる。実行環境に認証情報を渡せる場合は、`CIINII_USERNAME` と `CIINII_PASSWORD` を環境変数に設定して、スキルのディレクトリから次の補助コマンドを使う。実際のパスに置き換えて実行する。

```sh
python3 scripts/ciinii.py search '研究分野や手法'
python3 scripts/ciinii.py article '検索結果の詳細ページURL'
python3 scripts/ciinii.py pdf '詳細ページに表示された本文PDFのURL' /path/to/work/related-thesis.pdf
```

取得先には利用者の作業用ディレクトリを使う。認証できない、通信できない、または該当資料が見つからない場合は、状況を説明し、閲覧権限のある関連PDFや最新の指定テンプレートの添付を依頼する。公開の一次資料で確認できる章は先に進める。認証情報や取得した非公開資料をスキルのリポジトリや公開検索に送らない。公開検索語から個人情報や未公開の研究内容を除く。

学内の研究を本文の根拠に使った場合は、参照した論文の著者・題名・年度・資料種別・該当箇所を控え、閲覧制限にも配慮して指定書式で引用する。章構成だけを参考にした場合は作業メモに留める。先行研究の文章・図表・結果は、必要な引用と出典・利用条件を確認したうえで扱う。

## 公開資料

- [CiNii Research](https://cir.nii.ac.jp/)や[J-STAGE](https://www.jstage.jst.go.jp/)は文献探しに使い、引用する事実は原著、学会・出版社の掲載ページ、データ公開元、公式仕様で照合する。読めた範囲で主張を裏付け、書誌情報やDOIが未確認の場合は引用候補として保留する。
- 提出条件は学科・研究室の最新資料を確認する。[中京大学の在学生向けお知らせ](https://www.chukyo-u.ac.jp/student-staff/news/)にも全学の案内が出る。
- 章ごとの役割と記述の粒度の参考には、[香川大学・卒業論文／修士論文の書き方](https://stwww.eng.kagawa-u.ac.jp/~tarumi/sotsuron/howto.html)を使える。図表・引用・書誌情報の書き方は、指定がなければ [情報処理学会論文誌の執筆案内](https://www.ipsj.or.jp/journal/submit/ronbun_j_prms.html)を参考に統一する。
