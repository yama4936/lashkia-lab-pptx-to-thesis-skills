# 卒業発表から卒論へ

CiiiiNiiiiiiiiの過去の卒論と公開文献を参照し、卒業発表のPPTXから日本語のLaTeX原稿を作るCodexスキルです。編集用のTeXソース一式と、ビルドできた場合は確認用PDFを渡します。学科指定のテンプレートやWord形式の希望にも対応します。資料から判断できない点は、該当するスライドとともにチャットで質問します。

過去の卒論20本と発表資料がそろう10組から、スライドの内容をどの章でどう詳しく書くかを整理しました。通常の執筆はこの要約を使い、特定の研究を引用するときにその原典を確認します。[発表から本文への対応表](references/writing-patterns.md)

## 使い方

Codexで卒論の作業フォルダを開き、PPTXを添付して次のように依頼します。提出テンプレート、評価結果、図の元データがあれば一緒に添付できます。

```text
$pptx-to-thesis 添付した卒業発表PPTXから卒論原稿を作ってください。不足している情報はスライド番号付きで質問してください。
```

データベースを使うには、各利用者の閲覧権限が必要です。ログイン済みブラウザで閲覧するか、実行環境に `CIINII_USERNAME` と `CIINII_PASSWORD` を設定します。認証情報は管理者から入手してください。データベースへ接続できない環境では、閲覧権限のある関連卒論PDFを添付できます。補助スクリプトは追加パッケージなしで Python 3.9 以降で動きます。

## 別の作業フォルダ・環境に導入

卒論の作業フォルダで次を実行し、Codexでそのフォルダを開きます。Gitバンドルから導入する場合は、URLをバンドルのファイルパスに置き換えてください。

```sh
git clone https://github.com/yama4936/pptx-to-thesis.git .agents/skills/pptx-to-thesis
```

すべての作業フォルダで使いたい場合は、クローン先を `"$HOME/.agents/skills/pptx-to-thesis"` にします。[Codexのスキル配置ガイド](https://learn.chatgpt.com/docs/build-skills)

Gitにはスキル本体と補助コードを入れています。PPTX、過去卒論、認証情報、生成した原稿は利用者の作業フォルダで管理してください。
